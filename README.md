# MI-CALENDARIO-DE-TURNOS
Calendario web personal de turnos, preparado para GitHub Pages y futura sincronización con Firebase.

## Funciones iniciales
- Calendario mensual
- Turnos de mañana, tarde y noche
- Días libres, vacaciones, feriados e incapacidad
- Horas trabajadas y pago estimado
- Notas por día
- Almacenamiento local
- Diseño responsive/PWA
